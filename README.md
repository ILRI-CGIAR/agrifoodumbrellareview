# Agri-food umbrella review

R-based evidence retrieval and bibliographic preparation pipeline. The supported scope is W00 searching, W01 deduplication, W02 bibliographic enrichment, and W03 publication-status checks.

The implementation is adapted from [LivingEvidenceMap](https://github.com/thesalmonandthetomato/LivingEvidenceMap/tree/workflow01-final-architecture) with attribution. The source repository is read-only for this transfer.

**Status:** Migration in progress. Do not run production searches until a project-specific search strategy, API credentials, and restricted Zenodo settings are configured. No salmon-specific queries or prior Zenodo records should be reused.
